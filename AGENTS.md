# Правила работы над проектом

## Источник истины

`PLAN.md` в корне репозитория — единственный источник архитектурных решений.
Читай его перед началом любой задачи. Если задача противоречит плану — останови работу
и спроси, а не выбирай сам.

## Границы работы

- Работаем строго по одной фазе за раз. Не забегай вперёд, даже если «заодно легко сделать».
- Не коммить самостоятельно. Показывай изменения, коммитит человек.
- Не меняй решения из ЧАСТИ II плана (стек, схема БД, контракт API) без явного разрешения.
- В конце каждой задачи отдельным списком перечисли все решения, которые принял сам
  и которых нет в плане.

## Архитектурные инварианты

Нарушение любого из них — повод переделать, а не обсуждать:

1. **Слои backend.** `Domain` не знает ни о HTTP, ни о Doctrine, ни о Redis.
   `Http/Action` содержит только маппинг запрос → команда → ответ, ноль бизнес-логики.
   SQL живёт только в `Infrastructure/Persistence`.
2. **Статус — не поле формы.** Клиент никогда не присылает `status`. Статус меняется
   только через именованные методы сущности (`extendValidity`, `redeem`, `cancel`)
   и через Go-воркер (`active → expired`).
3. **Правило истечения живёт в одном месте.** Сравнение `expires_at` с текущим временем
   допустимо только в воркере и в `extendValidity()`. Нигде больше — ни в листинге,
   ни в сериализаторе, ни в React-компоненте.
4. **Деньги — целые в минорных единицах.** Никаких `float` и `string` для цены.
5. **Время — UTC.** В домене нет `new DateTime()`, только инжектируемые часы
   (`ClockInterface` в PHP, подменяемый источник времени в Go).
6. **Ошибки — единый контракт.** Все исключения превращаются в RFC 7807
   в одном месте, в `ErrorHandler`. Никаких `catch (\Exception) { return 500; }`
   и никаких исключений Doctrine, всплывающих в HTTP-ответ.
7. **Кеш необязателен.** Ошибка Redis логируется и запрос идёт в БД. Инвалидация —
   только через счётчик поколения, никогда через `KEYS`/`SCAN`.
8. **Токен недоступен браузерному JS.** Только httpOnly cookie, выставляемая
   Route Handler'ом Next.js. `localStorage` для токена запрещён.
9. **Мягкое удаление прозрачно.** Фильтр `deleted_at IS NULL` живёт в репозитории,
   а не в вызывающем коде.

## Качество

- PHP: PHPStan level 8 без ошибок, строгая типизация (`declare(strict_types=1)`).
- Go: `go vet` и `golangci-lint run` чисто, `go test -race` без гонок.
- TS: `tsc --noEmit` без ошибок, `strict: true`, никаких `any`.
- Тесты проверяют бизнес-правила и границы, а не геттеры. Тест без утверждения о поведении
  писать не нужно.
- Не оставляй закомментированный код, TODO и отладочный вывод.

## Стиль

- Комментарии — только там, где объясняют «почему», а не «что».
- Именование на английском, сообщения об ошибках для пользователя — на русском.
- Никаких заглушек с `throw new Exception('not implemented')` в сдаваемом коде.
